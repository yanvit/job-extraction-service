# Корпус вакансій Software Engineering (Djinni, жовтень 2026)

Окремий від ДЗ1 набір для наступних етапів курсу (RAG, агент). Дані ДЗ1 (`data/raw`, `data/golden.jsonl`) заморожені й не змінюються.

**Файл:** `djinni_se_raw.jsonl` — 150 вакансій, по JSON-об'єкту на рядок.

| Поле | Що це |
|---|---|
| `id` | id вакансії на Djinni |
| `url` | посилання на вакансію |
| `keyword` | основна технологія, за якою знайдено (фільтр `primary_keyword` на Djinni) |
| `title` | назва вакансії |
| `published` | рядок дати публікації з Djinni («Опубліковано 28 жовтня») |
| `text` | повний текст: заголовок, компанія, вилка (якщо є), опис, вимоги до мов + метадані сайдбару через ` \| ` |

**Склад:** 10 вакансій на кожен стек:
- мови: Python, Java, JavaScript, Node.js, PHP, .NET, Golang, C++;
- мобільна розробка: iOS, Android, React Native;
- дані: Data Engineer, Data Science.

Менше вакансій у стеках: Rust (8), Flutter (6), Ruby (3), Scala (3). DevOps і QA Automation зібрати не встигли (див. нижче).

**Характеристики:**
- мова опису: ~102 англійською, ~48 українською (груба оцінка за алфавітом);
- довжина від 1 до 11 тис. символів, медіана ~3 тис.;
- конкретна зарплата вказана лише в ~26 з 150, решта — `$`–`$$$$`;
- переважно опубліковані 14–29 жовтня 2026.

**Як зібрано:** 2026-10-29, публічні сторінки вакансій Djinni, відкриті у браузері на моєму ноутбуці; текст витягнуто зі сторінки без переписування. Перевірка на персональні дані (email, телефони, @-акаунти, LinkedIn/t.me посилання, «Recruiter: Ім'я») — 0 збігів.

**Обмеження:**
- Тільки одне джерело (Djinni). Тексти чистіші й структурованіші за Telegram-пости з ДЗ1.
- Під час збору Djinni тимчасово заблокував IP через надто часті запити, тому корпус зупинився на 150. Без DevOps / QA Automation.
- Наступні добори — лише з паузами між запитами.
