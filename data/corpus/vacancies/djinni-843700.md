# Senior Golang Developer

GameInspire

$$$$

Продуктова компанія

Ми — продуктова компанія, яка активно розширює свою присутність на ринку iGaming. Наша місія — створювати технологічно розвинені, гнучкі та модульні рішення для індустрії.
Наш ключовий продукт — це ігрова SaaS-платформа, яка об’єднує понад 200 сервісів і забезпечує найкращий ігровий досвід для мільйонів гравців по всьому світу. Платформа включає все необхідне для iGaming-операторів: управління іграми, платежі, аналітику, CRM та інші модулі.

Ми розширюємо команду та шукаємо Senior Golang Developer’ів, яким цікаво вирішувати реальні технічні задачі.
Пропонуємо продуктове середовище, можливості для професійного зростання та свободу впливати на інженерні рішення.

Обов’язки
- Проєктування, розробка та підтримка backend-сервісів на Go;
- Підтримка та покращення наявної функціональності системи;
- Реалізація нових функцій, сервісів та інфраструктурних компонентів;
- Оптимізація продуктивності, масштабованості та доступності системи;
- Написання чистого, підтримуваного та добре задокументованого коду;
- Участь у code review та технічних обговореннях.

Вимоги
- 5+ років комерційного досвіду в розробці, з них мінімум 3 роки з Go;
- Практичний досвід роботи з RabbitMQ або подібними message brokers;
- Досвід роботи з MongoDB, включно з моделюванням даних та оптимізацією продуктивності;
- Знайомство з Elasticsearch для пошуку, аналітики або логування;
- Досвід роботи з Grafana та Prometheus для моніторингу й observability;
- Хороше розуміння мікросервісної архітектури та розподілених систем;
- Досвід проєктування та інтеграції REST API;
- Практичний досвід роботи з Kubernetes.

Буде плюсом
- Базові або середні знання PHP для підтримки наявних сервісів, приблизно 20% навантаження;
- Досвід роботи з high-load системами;
- Розуміння event-driven architecture;
- Досвід роботи з CI/CD pipelines та cloud infrastructure;
- Досвід використання AI-інструментів для розробки, наприклад Claude, ChatGPT, GitHub Copilot, буде плюсом.

- Медичне страхування (в Україні) та підтримку здоров’я
