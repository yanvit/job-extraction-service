# React Native Developer

Stormotion

$

Ukraine-based role

Stormotion is a React Native-focused agency. We build mobile products in IoT/BLE, EV & Mobility, Fitness, and HealthTech/Mental Wellbeing. Small teams, direct client communication.

Growth path
Start as a React Native developer. Over time you can add React (web) and grow to Full Stack with Hasura + PostgreSQL + Nest.js.

What you’ll do
- Build and ship React Native apps (TypeScript)
- Turn product goals into working solutions (not just “implement tickets”)
- Keep releases stable - test key flows in real conditions
- Make scope/architecture decisions that won’t block future scaling
- Code reviews, mentoring, workshops (everyone teaches, everyone learns)
- Join client calls: clarify requirements, explain trade-offs, drive discussions

Must have
- 1+ year commercial React Native experience
- Strong TypeScript
- Hooks + Context
- State management (Redux / MobX or similar)
- API integration (fetch / axios or similar)
- Spoken English Intermediate+: confident on calls, not only in chat
- Tech education (Computer Science, IT, Cybersecurity, etc)

Nice to have
- GraphQL (Apollo Client / Relay / urql)
- Push notifications
- Firebase (Cloud Messaging, Analytics, Firestore, Storage, Authentication, Functions)
- React Navigation
- ESLint / Prettier
- Testing (TDD / Jest / Detox)
- CI/CD (Fastlane / GitLab CI/CD / GitHub Actions)
- Reanimated 3 / React Native Skia
- BLE integrations (react-native-ble-plx or similar)
- Ramda / Lodash / fp-ts or other FP libraries

Benefits
- 24 paid vacation days + 10 paid recharge days
- Birthday day-off + Donor day-off
- Remote-first, office option in Dnipro
- Professional study compensation (courses/meetups/webinars)
- Sport & Streamings budgets
- Assistance with taxation PE documentation
