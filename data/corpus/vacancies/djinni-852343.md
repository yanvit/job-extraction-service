🚀 AIMPROSOFT is looking for a Java Tech Lead / Solution Architect (React , Telecom)

Aimprosoft, a fast-growing IT company, is looking for a Java Tech Lead / Solution Architect (React , Telecom) on a contract basis ( 4+ months) an international project in the Telecommunications / BSS-OSS domain.

This is a senior hands-on role for an experienced Java engineer who combines solution architecture, technical leadership, and production development. You will join the project first, shape the technical foundation during discovery, and then lead a team of three Full-Stack Java Developers through the MVP delivery.

The role is approximately 50% architecture and technical leadership / 50% hands-on production coding.

## 🎯 About the project & role

The client is a UK wholesale internet service provider supplying broadband, Ethernet, and connectivity services to resellers and partners.
The project is Phase 1 of a new customer and admin portal and integration platform (BSS/OSS) designed to replace manual and legacy processes and become the first production slice of the client's target platform.

## The technical environment includes

- Java & Spring Boot
- React & TypeScript
- Microservices and event-driven architecture
- PostgreSQL
- BPMN / workflow orchestration
- OAuth2 / OIDC and Auth0
- AWS
- Docker and Kubernetes
- CI/CD
- TM Forum Open APIs

## 🎯 Your key responsibilities will include

- Owning the solution architecture for the client portal and integration platform
- Leading the initial technical discovery and helping define the MVP implementation approach
- Designing domain models, APIs, integration flows, and event-driven components
- Writing production Java / Spring Boot code, particularly for technically complex parts of the platform
- Leading and mentoring a team of three Full-Stack Java Developers
- Reviewing code and establishing engineering standards and quality gates
- Guiding the React portal architecture and UI standards
- Designing integrations with external and legacy systems
- Making and documenting architecture decisions using ADRs and C4 diagrams
- Working closely with DevOps and QA on AWS environments, CI/CD, contract testing, and integrations
- Communicating directly with the UK client and third-party technical teams
- Presenting technical progress through regular live demos

## 🔥 What We Need From You

- Hands-on experience in the Telecommunications domain, ideally with ISP, BSS/OSS, broadband, order management, product catalogues, or service qualification
- Experience with TM Forum Open APIs
- 8+ years of commercial Java development experience
- 2+ years as a Tech Lead, Solution Architect, or in a similar technical leadership role
- Strong hands-on experience with Spring Boot
- 3–4+ years of hands-on experience with React / ReactJS and TypeScript
- English: Upper-Intermediate (B2+) / Advanced (C1) for direct communication with a UK client
- Experience designing and delivering microservice and integration-heavy systems
- Strong understanding of Domain-Driven Design (DDD) and event-driven architecture
- Ability to review frontend code, guide React application architecture and contribute to frontend development when needed
- Practical experience with reliability and integration patterns such as Transactional Outbox, idempotency, retries, and asynchronous processing
- Experience designing REST APIs and OpenAPI-based contracts
- Experience integrating with multiple external systems and third-party APIs
- Practical experience with Camunda, Flowable, or a similar workflow / orchestration engine
- Practical experience with OAuth2 / OIDC, Spring Security, and RBAC
- Hands-on experience with AWS and containerized environments (EKS or ECS, Docker)
- Understanding of CI/CD and modern software delivery practices
- Experience with AI-assisted development tools such as Claude Code or Cursor
- Experience leading developers through technical planning, code reviews, mentoring, and delivery
