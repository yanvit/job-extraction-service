# SDET for iOS(Swift) - Tinder

Zoolatech

$$$$

A large-scale consumer mobile application with millions of active users required a robust testing strategy to ensure stability, performance, and seamless user experience. Testing efforts focused on both iOS and Android platforms, covering functional validation, UI/UX consistency, geolocation features, and real-time interactions.

Responsibilities

- Contribute as a key member of a world-class Android Engineering and QA Automation team.
- Design, implement, and maintain automated test cases and frameworks in Kotlin, JUnit, Espresso.
- Own the quality lifecycle: identify issues, file and track bugs in Qase(or similar systems), and drive them to resolution.
- Collaborate closely with Android engineers to ensure application code is testable and automation-friendly.
- Build and maintain in-house tools for test parallelization, network mocking, and custom reporting.
- Perform peer code reviews, ensuring robust test coverage and reliable CI pipelines.
- Drive improvements to the CI/CD ecosystem, ensuring scalability, maintainability, and speed of test execution.
- Explore and integrate AI-assisted development approaches to enhance test generation, workflow optimization, and CI/CD practices.
- Actively participate in Agile ceremonies – daily standups, sprint planning, retrospectives, and showcases.

Skills Required
- 2+ years of experience as an SDET, QA Automation Engineer, or related role, with a strong focus on Android application testing.
- Proficient in Kotlin and the Android SDK, with strong debugging and troubleshooting skills.
- Hands-on experience with JUnit, Espresso and UI automation.
- Experience with dependency injection frameworks (Dagger/Hilt) and API testing using Retrofit.
- Familiarity with Jetpack libraries and modern Android development best practices.
- Strong experience with Git/GitHub, familiar with both Gitflow and trunk-based development.
- Knowledge of SOLID principles and ability to apply them in test framework design.
- Ability to apply or readiness to adopt AI-driven testing practices, including test generation and workflow automation.
- Strong English communication skills
