Шукаємо досвідченого Android-розробника, який працюватиме над мобільними продуктами для потреб оборони України. Ви будете відповідати за розробку та розвиток застосунків: від архітектури й інтеграції з системними можливостями ОС до безпеки та стабільної роботи на пристроях користувачів.

### Чим займатиметесь
- Розробка нових і підтримка наявних мобільних застосунків для Android
- Оптимізація фонових процесів: стабільність, енергоспоживання, коректна робота в різних станах системи
- Реалізація механізмів роботи з файловою системою
- Інтеграція із системними компонентами Android OS
- Впровадження заходів безпеки в застосунках
- Взаємодія з користувачами, збір зворотного зв'язку та робота над покращеннями продукту

### Що очікуємо
- Комерційний досвід розробки Android-застосунків
- Впевнене знання Kotlin та/або Java
- Глибоке розуміння Android SDK
- Досвід роботи з Jetpack Compose
- Вміння працювати з асинхронними API
- Досвід використання Accessibility API
- Готовність до роботи в офісі в Києві за 6-денним графіком

### Буде перевагою
- Досвід роботи з Flutter/Dart

### Ми пропонуємо
- Роботу над продуктами, що безпосередньо впливають на обороноздатність України
- Команду сильних інженерів, які розв'язують реальні задачі
- Можливість бронювання відповідно до чинного законодавства
- Офіційне працевлаштування та соціальні гарантії згідно з КЗпП України
- Оплачувані відпустки та лікарняні
- Компенсацію оренди житла при переїзді з інших регіонів
- Конкурентну винагороду
- Можливість відряджень
- Можливості для професійного розвитку, власних ініціатив і впливу на кінцевий результат
