# Middle Data Engineer (Python)

Nova Digital

🔥

$$

🇺🇦 Український продукт

Nova Digital — це технологічне серце екосистеми NOVA, де твій код стає частиною щоденного життя цілої країни. Не просто код, а твій вплив на мільйони українців.

## Про масштаб наших сервісів

- 50+ млн запитів щодня проходять через наші системи
- 10+ млн активних користувачів покладаються на наші рішення

Ми будуємо не просто продукт — ми створюємо технологічну інфраструктуру, яка об’єднує людей, бізнеси та можливості вже майже по цілому світу. Шукаємо Middle Data Engineer для розробки та підтримки проектів що забезпечують безперебійну, стабільну та швидку роботу звітності компанії, що будується на основі мільйонів рядків даних та оновлюється з частотою до 10 хв.

## Що робитимеш як Middle Data Engineer

- Розробка / Налаштування API методів для обміну даних
- Розробка дашбордів, написання SQL-скриптів
- Робота з PostgreSQL (1 млн.+ рядків)
- Підтримка та оптимізація існуючих розробок
- Ведення проектів у Git, робота з гілками та налаштування CI/CD

## Твій ідеальний профіль

Must-have
- Python 2+ роки (DocString, типізація, лінтери)
- Airflow, від 6 міс
- Впевнене володіння SQL (віконні функції)

Nice-to-have
