# Flutter Engineer

NDA Recruitment

🔥

$$$$

🪖 DefTech

Продуктова компанія

Ми шукаємо Flutter Developer, який долучиться до розробки та розвитку сучасного кросплатформного застосунку.
На цій позиції ви працюватимете над UI та клієнтською архітектурою, реалізацією інтеграцій із різними системами, REST API, WebSockets та real-time даними.
На вас чекають цікаві технічні виклики, робота над новими можливостями продукту, свобода у прийнятті технічних рішень та співпраця з командою професіоналів.

## Основні задачі

- Розробка та розвиток клієнтської частини на Flutter.
- Проєктування UI та клієнтської архітектури для нових функцій та інтеграцій.
- Реалізація інтеграційних сценаріїв з іншими системами.
- Розвиток універсального та зручного інтерфейсу для роботи з різними платформами.
- Розробка UI-сценаріїв для конфігурації, біндінгу та керування підключеннями.
- Робота з real-time даними, API та станами підключення.
- Спільна робота з Backend, QA, Product та Tech Lead над архітектурою та реалізацією функціоналу.
- Участь у технічному дизайні нових інтеграцій ще до початку їх реалізації.
- Підтримка якості коду, code review та розвиток інженерних практик команди.

## Основні вимоги

- Сильний комерційний досвід розробки на Flutter / Dart.
- Практичний досвід побудови та розвитку production-grade Flutter applications.
- Розуміння Clean Architecture, SOLID та принципів модульної архітектури.
- Досвід із state management, бажано BLoC / Cubit, Riverpod або аналогами.
- Досвід інтеграції з REST API та WebSockets.
- Розуміння asynchronous programming та роботи з real-time даними.
- Досвід інтеграції Flutter із native Android/iOS можливостями через Method Channels / Flutter Plugins.
- Досвід performance optimization та debugging.
- Git та робота з CI/CD.
- Здатність самостійно декомпозувати складну технічну задачу та доводити її до production-ready результату.
- Досвід роботи у кросфункціональній команді з Backend, QA, Product та Design.
