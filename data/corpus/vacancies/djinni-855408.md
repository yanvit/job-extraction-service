Hi! We are looking for a Middle Backend Engineer to develop the backend for a new AI-powered video recording and editing platform with Mobile, Web, and Desktop clients.

Key Responsibilities
- Design, develop, and maintain backend services for cross-platform applications.
- Build REST APIs for content management, including secure S3 uploads, media metadata, thumbnails, and scheduling.
- Orchestrate video processing jobs using existing AI workers on RunPod, including job scheduling, status tracking, and error handling.
- Integrate third-party services for payments, analytics, AI, and API security (e.g., RevenueCat, Firebase App Check, OpenAI).
- Implement real-time communication and state synchronization between clients using WebSockets.
- Develop and maintain background jobs, queues, and scheduled tasks.
- Collaborate with product managers and client application developers.
- Participate in architectural decisions and technical improvements.

Requirements
- Solid experience with backend frameworks, databases, and database design.
- Understanding of authentication, authorization, and API security.
- Experience integrating third-party APIs and handling webhooks.
- Experience with Docker, Git, and CI/CD pipelines.
- Ability to deliver maintainable, production-ready code.
