Команда YouControl – люди, які спільно створюють технологічні продукти, втілюючи єдину місію – сприяти розширенню міжнародної співпраці шляхом формування прозорого бізнес-середовища.

## Що потрібно, щоб приєднатися до нас

- Expertise: 5+ років комерційного досвіду з C# / .NET.
- System Design: Глибоке розуміння архітектурних підходів, досвід побудови Backend-сервісів та API.
- Concurrency: Впевнена робота з асинхронністю та багатопотоковістю (Task Parallel Library, async/await).
- Integrations: Досвід інтеграції з різноманітними зовнішніми сервісами та API.
- Data & Messaging: * Досвід проектування реляційних БД.- Робота з брокерами повідомлень (RabbitMQ або аналоги).

- Tools: Впевнене володіння Git (GitLab) та досвід роботи у повному життєвому циклі розробки (SDLC).

## ⭐️ Буде плюсом

- Досвід у ролі неформального лідера або ментора.

- Досвід роботи з Redis / NoSQL базами даних.

- Розробка та розвиток технічних рішень продукту;

- Допомога команді у прийнятті технічних рішень разом із технічним лідом;
- Проведення code review та підтримка стандартів якості коду;
- Менторинг і розвиток розробників у команді.
