Шукаємо Senior Back-End розробника на існуючий проєкт, який активно розвивається. Бекенд складається з кількох мікросервісів на Node.js / TypeScript. Робота включає розвиток і масштабування системи, рефакторинг, створення нових сервісів та інтеграцію із зовнішніми системами. У команді налагоджено code review, автотести та CI.

## Обов'язки

- Розвиток, підтримка й масштабування існуючої мікросервісної системи
- Проєктування та розробка нових сервісів, розширення наявних
- Інтеграція сервісів між собою, із зовнішніми системами та клієнтською частиною
- Проєктування та реалізація RESTful API, підтримка API-документації (OpenAPI / Swagger)
- Асинхронна взаємодія між сервісами через черги повідомлень
- Робота з реляційною БД: моделювання даних, міграції, оптимізація запитів
- Реалізація розмежування доступу та інших механізмів безпеки на рівні API
- Написання unit- та інтеграційних тестів
- Діагностика й усунення проблем, оптимізація продуктивності та рефакторинг коду
- Участь в обговоренні архітектури та code review, пропозиції технічних рішень

## Вимоги

- Від 6 років комерційного досвіду в back-end розробці
- Впевнене знання Node.js і TypeScript
- Досвід із NestJS (або глибоке знання Express.js і готовність швидко перейти на NestJS)
- PostgreSQL: проєктування схем, транзакції, індекси, оптимізація запитів
- Досвід з ORM (Prisma, TypeORM або аналоги)
- Розуміння мікросервісної архітектури та практичний досвід роботи з нею
- Досвід з брокерами повідомлень (RabbitMQ або аналоги) і Redis
- Розуміння принципів ООП, SOLID, патернів проєктування
- Досвід автоматизованого тестування (Jest або аналоги)
- Docker, Git, базове розуміння CI/CD
- Досвід з Postman або аналогічними інструментами для роботи з API
- Розуміння основ безпеки веб-застосунків

## Буде перевагою

- Досвід побудови рольових моделей доступу (RBAC / ABAC)
- Real-time взаємодія: WebSocket, Server-Sent Events
- Моніторинг і спостережуваність: Prometheus, структуроване логування
- Інтеграції через SOAP
- Робота з криптографічними бібліотеками та електронним цифровим підписом (ЕЦП / КЕП)
- Знання Vue.js або Angular на рівні, достатньому для взаємодії з фронтенд-командою
