# Senior Mobile Engineer - React Native + Expo

Mobalytics

до $6000

Продуктова компанія

The Mobalytics mission is to create the ultimate gaming companion, providing powerful tools that enable all players to step up their game and be their best selves.

Over the past few years, we have gone from just servicing League of Legends players to empowering players of different genres through Teamfight Tactics, Diablo 4, Path of Exile 2, and many many more. Millions of players get game advice from Mobalytics every day, and now we want to be in their pocket too.

We're building the Mobalytics mobile app from the ground up, and we're looking for the engineer at its core. This is a hands-on, coder-first role: you'll write a large part of the app yourself and lead by example through your code, architecture and reviews. This isn't porting a website to a phone. It's building something players reach for between matches, in the queue and on the go.

Our Mobile Stack
- React Native with Expo (SDK, Expo Router, development builds)
- TypeScript everywhere
- EAS Build, EAS Submit and EAS Update for builds, store delivery and OTA updates
- GraphQL APIs backed by our Go microservices
- Mixpanel for product analytics

Your Responsibilities
- Build the app's foundation hands-on: architecture, navigation, state and data layer, offline behaviour, theming and a shared component library
- Write and ship features, and set the coding standards and patterns the rest of the squad follows
- Be the React Native reference for the team: review code and pair with React developers as they make the move to mobile
- Make the app feel native on both iOS and Android: performance, animations, gestures, haptics, push notifications and deep links
- Own the mobile release flow (signing, versioning, TestFlight and Play testing tracks, staged rollouts, OTA updates), together with our DevOps team, who handle CI/CD infrastructure
- Work with the Product and design team to decide what a phone does better than a desktop.

Your Technical Skill Set
- 5+ years of software engineering experience, with at least 3 years working mainly in React Native
- Shipped and maintained production React Native apps on both the App Store and Google Play. Please include store links in your application. Web React experience alone isn't enough for this role
- Solid React web background, enough to know where web habits break on mobile and to help others avoid those traps
- Hands-on experience with Expo: managed workflow and development builds, Expo Router, config plugins, and EAS Build, Submit and Update
- Strong TypeScript and modern React (Hooks, Suspense, performance profiling)
- Solid understanding of the React Native New Architecture (Fabric, TurboModules) and of when a native module is needed (Expo Modules API is a plus)
- Experience with Reanimated and Gesture Handler, and you care about 60 fps scrolling and smooth transitions
- Experience with GraphQL or REST data layers and caching (Apollo, TanStack Query or similar)
- Familiarity with mobile testing at different levels (Jest, React Native Testing Library, Detox or Maestro)
- Comfortable reading and debugging Swift/Kotlin and Xcode/Gradle builds when something breaks below the JavaScript layer

Your Personal Skill Set
- You'd rather open a PR than a slide deck, and you lead with working code
- You enjoy sharing what you know, and a good code review or pairing session is part of the job for you, not a distraction from it
- You want to do a job that means something, and to build things people love
- You speak up when the team is heading down the wrong path
- You are fluent in English. You'll work daily with global stakeholders and cross-functional team members in English.

Would be a plus
- Experience building an app from scratch (0 → 1) rather than only maintaining one
- Experience helping web developers move to React Native
- Experience with push notification strategy, in-app purchases or subscriptions
- Native iOS (Swift) or Android (Kotlin) development experience
- We don't care if you're ranked Bronze or Diamond, but familiarity with the games we support helps you understand what our players need

What we offer
- Real ownership: you'll shape a product from the very beginning, in a flat organization where good ideas win, not titles
- Fully Remote Job: we've been a remote company from day one
- Flexible working hours: apart from scheduled meetings, we don't have a set schedule or a required number of hours. Mobalytics is about results, not hours spent
- Salary paid in USD, wherever you are in the world
- 15 vacation days + 2 more weeks of company-wide vacation in Dec–Jan + 10 sick days

If you love games and want to build a mobile product for passionate communities of competitive gamers, this is the place for you.
