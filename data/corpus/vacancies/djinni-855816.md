# Senior React Native / React Developer

Influence Pro Services

$$$

Продуктова компанія

Ми створюємо й запускаємо B2C-продукти за підпискою для ринку США - від першого лендингу до мобільного застосунку та масштабування бізнесу.
Наші продукти мають спільну технологічну базу. Ми працюємо короткими циклами, перевіряємо попит на реальному трафіку й ухвалюємо рішення на основі юніт-економіки. Будуємо прозору підпискову модель зі зрозумілими цінами та простим скасуванням.

Про роль
Шукаємо розробника із сильними знаннями React Native та React, який долучиться до створення мобільних застосунків для iOS та Android і розвитку їхньої веб частини.
Ви працюватимете над кількома продуктами на різних етапах: від прототипів і перших MVP до розвитку та масштабування. Основний фокус — мобільні застосунки, їхні користувацькі сценарії та інтеграція з вебпродуктами.
Працюватимете разом із технічним лідом, бекенд-розробниками, продуктом, дизайном і growth-командою. Ваші рішення безпосередньо впливатимуть на користувацький досвід, конверсію та бізнес-результати.

Що ви робитимете
- Створюватимете й розвиватимете мобільні застосунки для iOS та Android на React Native.
- Розроблятимете веб частину продуктів на React: лендинги, онбординг-квізи, пейволи, сторінки оплати й особисті кабінети.
- Реалізовуватимете користувацькі сценарії: від першого знайомства з продуктом до оформлення підписки та використання застосунку.
- Перетворюватимете дизайни з Figma й AI-прототипи на якісний код, який легко підтримувати.
- Створюватимете й підтримуватимете перевикористовувані компоненти та узгоджену дизайн-систему для мобільних і вебпродуктів.
- Інтегруватимете API, платіжні рішення та сценарії керування підпискою.
- Впроваджуватимете аналітику й трекінг подій, допомагатимете запускати A/B-тести та продуктові експерименти.
- Оптимізуватимете швидкодію, стабільність застосунків і конверсію ключових етапів воронки.
- Братимете участь у підготовці та випуску мобільних застосунків в App Store і Google Play.
- Працюватимете із задачами в Jira, вестимете документацію в Confluence та долучатиметеся до код-рев’ю, тестування й покращення CI/CD.

Що для нас важливо
- Практичний досвід створення та підтримки мобільних застосунків на React Native.
- Розуміння особливостей iOS та Android, мобільної навігації, життєвого циклу застосунку й роботи з платформними інтеграціями.
- Впевнене володіння сучасними підходами до керування станом, роботи з API та завантаження даних.
- Сильні HTML і CSS для вебчастини, досвід адаптивної верстки та увага до деталей інтерфейсу.
- Уміння працювати з Figma, компонентами дизайн-системи та обговорювати реалізацію з дизайнером.
- Практичне використання AI-інструментів розробки та здатність оцінювати якість згенерованого коду.
- Досвід автоматизованого тестування, роботи з Git і CI/CD.
- Англійська, достатня для роботи з документацією та технічних обговорень.

- Досвід інтеграції покупок і підписок через App Store / Google Play або RevenueCat.

- Даєте чесний фідбек і вмієте аргументувати технічні та продуктові пропозиції.
