Продуктова компанія

Ми шукаємо досвідченого Python Backend Developer, який приєднається до нашої команди для розвитку backend-архітектури мобільного продукту. Ваша робота буде зосереджена на забезпеченні стабільності системи, роботі з телематичними даними та інтеграції сучасних сервісів.
Ваші основні задачі:
- Проєктування та підтримка високонавантаженої backend-архітектури мобільного додатка.
- Проєктування, розвиток та підтримка стабільного REST API.
- Інтеграція з GPS/телематичними сервісами, картами, платіжними системами та іншими зовнішніми API.
- Робота з базами даних (PostgreSQL, MongoDB, Redis), включаючи їх оптимізацію та масштабування.
- Забезпечення високої продуктивності, безпеки та відмовостійкості продукту.
- Співпраця з Project Manager, Frontend та Mobile командами для досягнення спільних цілей.
- Проведення Code review та активна участь у покращенні якості технічних рішень.
- Участь у плануванні технічного розвитку продукту.

Наші очікування від кандидата:
- Досвід від 3 років досвіду комерційної backend-розробки.
- Впевнені знання Python, зокрема досвід роботи з FastAPI, FastStream та SQLAlchemy.
- Експертиза в PostgreSQL (PostGIS), досвід роботи з RabbitMQ, MongoDB та Redis.
- Розуміння принципів побудови масштабованих та high-load систем.
- Впевнене володіння Git.

Буде значною перевагою:
- Досвід роботи у сфері GPS, IoT або телематичних систем.
- Успішний досвід інтеграції зовнішніх сервісів (платежі, карти, SMS-шлюзи).
- Досвід роботи з Docker та розуміння загальних DevOps-процесів
