# Judge prompt changelog

Промпти LLM-судді для evals (`evals/scoring.py`). Версія і хеш логуються в `evals/results/answers.jsonl` (`judge_version`, `judge_sha`).
Старі версії не редагуються — нова версія + запис тут + повторна калібровка (`make calibrate`).

## v1 — 2026-11-23
- `correctness.md`: correct / partial / incorrect проти еталонної відповіді з тестсету; точне порівняння цифр; відповідь про інший період чи версію і безпідставна відмова — `incorrect`.
- `faithfulness.md`: для кожного твердження окремо — чи випливає воно з процитованих ним джерел (а не з будь-якого джерела контексту і не з загальних знань).
- Суддя — Claude Opus 5.5, сильніша модель, ніж та, що відповідає (Haiku 5.5): менше «самовподобання» і краща точність на цифрах.
